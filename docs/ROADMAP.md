## 将来の研究課題（v1以降）

- AIの生成をオプションとして追加するか

## 非目標（当面）

- 実在マンションの物件広告自動作成
- 不動産価格・資産価値の予測
- 正確な徒歩分数・眺望・騒音等の保証
- APIキーを静的ページに埋め込む方式
- 大規模な独自バックエンドやログイン基盤

## 作業順序

1. GitHub上でv0.1を保全する。
2. GitHub Pagesを公開して端末間での実機確認を行う。
3. UIの磨き込み、入力状態、外部API障害への対応を優先する。
4. 出典のある地理データを段階的に追加する。
5. 最後にポエム生成品質の拡充と画像化を進める。

作業のたびにREADMEと本ロードマップを更新し、実装済／未実装を混同しない。
