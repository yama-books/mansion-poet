## 継続課題

1. REF-0003/0004には、真に独立したTYPE POEM / EDITORIAL / LOCATIONをA4判型でそれぞれ設計する必要がある。生成画の小文字・架空販売値をトレースしない。
2. REF-0005〜0008は図版・文字の関係を検討するための「編集モック」であり、高級広告の写実的な写真・材質描写は未到達。独立ART制作後に比較する。
3. 4枚に共通する三列一覧は監査の器として統一したもの。実際の広告（A〜F）の内部構造とテーマ別画像は異なるが、構図の独創性を確保するには次段階の個別レイアウト制作が必要。
4. 地図・凡例は完全な架空模式図。「架空」の文字を明示したが、実装時は地理院タイルまたは検証済みの座標に置換。生成価格・徒歩分・施設名は一切採用しない。
5. 印刷適性は設計仮説のみ。A4 PDF・iPhone表示・実効ppi・白黒・表裏での改行について検証実績なし。
