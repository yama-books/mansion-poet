# マンションポエムメーカー：構想・製品コンセプト

更新日：2026-10-16  
プロジェクト名：**mansion-poet**  
仮ブランド：**POÈME / ESTATE**  
状態：コンセプト策定／軽量Web試作版 v0.1

## 1. 何を作るか

日本全国の任意の場所を地図・地名から選ぶと、その場所の土地・地形・交通・施設・歴史・文化の特徴を読み取り、**高級マンション広告にありがちな、格調高く、抽象的で、ときに大げさな「マンションポエム」**を作るWebアプリ。

単に定型句を無作為に組み合わせるのではなく、**「その土地だから生まれるポエム」**を目指す。高級住宅地だけでなく、無名の住宅街や駅から遠い場所も、そこならではの意味を見つけて壮大に賛美する。

**主眼は創作・パロディ・地理への好奇心**。実在のマンションの広告・購入判断には使わない。

## 2. 体験の中心

1. 全国から好きな地名を検索、または地図上の地点を指定する。
2. その地点の周辺情報を取得し、土地を特徴づける素材を抽出する。
3. 「格式・邸宅」「都市・先進」「自然・静寂」などの文体とポエム濃度を選ぶ。
4. 架空の物件名、キャッチコピー、広告本文を生成する。
5. コピー、再生成、印刷、後続版では広告画像化・共有を行う。
6. 生成の根拠として、取得できた地名・施設名・特徴を閲覧できる。

例（すべて架空の創作文）：

| 入力・特徴 | 出力イメージ |
| --- | --- |
| 神保町・書店街・文化 | 「知の深奥に、邸の答えを。」 |
| 丘陵地・坂道 | 「高みを、住まう。」 |
| 駅から距離がある住宅地 | 「都市の速度を脱ぎ捨てる、私邸の領域。」 |
| 河川や海に近い | 「水脈の記憶を、暮らしの誇りへ。」 |

**禁止事項：** 地名や施設から裏付けられない「眺望が保証される」「駅徒歩何分」「絶対に静か」「資産価値が上がる」など、事実と誤認させる断定を出さない。

## 3. ビジュアルコンセプト

**「架空の超高級レジデンス公式サイトそのもの」**。

- 都市建築のように整理されたグリッドと、大胆すぎる余白。
- 深緑／チャコール、アイボリー、シャンパンゴールドを基調とする抑制された配色。
- 英字のエディトリアルなセリフ体と、日本語の品位ある明朝体を組み合わせる。
- 極細の罫線、細やかなレタースペーシング、号数・番地・座標などをデザイン要素にする。
- 建築ビジュアルは実在物件だと誤認されないオリジナルの画像・図版を使う。
- 控えめなフェード、スライド、テキストの時間差登場。操作性と軽さを優先し、過剰な演出や重い動画は避ける。
- スマートフォンでも読みやすく、主要機能を1画面の流れで完結させる。

**ユーモアの出し方：** UIは終始真剣で、文章だけが限界まで荘厳になる。安易なギャグ装飾や派手な色を使わない。

## 4. 生成設計の基本方針

### 4.1 入力

- 地名／住所の検索語
- 地図クリックで指定した緯度・経度
- ポエムの文体
- ポエム濃度（0〜100）
- 将来：半径、含めたい施設・地形・地域文化、文章の長さ、架空物件の格

### 4.2 土地特徴の分類

- **都市性：** 鉄道、駅、街路、商業・業務系施設
- **知性／文教：** 学校、大学、図書館、書店、研究施設
- **歴史／継承：** 史跡、文化財、旧地名、街の変遷
- **自然／静寂：** 公園、緑地、標高、地形、河川、海岸
- **文化／芸術：** 美術館、博物館、ギャラリー、劇場
- **日常性：** 生活施設、商店街、地域らしい普通の風景

複数ある特徴から優先度をつけて主題を選び、ポエムの構文に写像する。

### 4.3 文章の出力構造

1. 架空の英語・日本語物件名
2. 強い一行のキャッチコピー（必要なら改行）
3. 3〜5行程度の短い広告本文
4. 地名、参照した地域情報、「これは架空の創作」という注記
5. 将来：別案・短文／長文・SNS共有カード

**同じ地点でも再生成により異なる切り口が出ること**を重視する。ただし、同じ事実を矛盾する形で言い換えない。

### 4.4 生成技術

- **第1段階：辞書・テンプレート方式。** ブラウザー内で動作。APIキーなし・コストなし・再現しやすい。
- **第2段階：地域特徴のスコアリングと構文拡充。** 事実の根拠を持ち、ありきたりな文の重複を減らす。
- **第3段階：任意のLLM生成。** 既定はローカル生成のまま、利用者が設定した場合のみ外部の生成APIを使える形を検討。秘密鍵を静的公開HTMLに埋め込まない。

## 5. v0.1でできること

- 全国の地名・住所検索（国土地理院の外部APIに接続できる場合）
- 地図上で地点選択（Leaflet、国土地理院タイル）
- 指定地点近傍の一部施設検索（OSM/Overpass、通信成功時）
- 格式・都市・自然の3文体
- 0〜100のポエム濃度調整
- 架空物件名／見出し／広告本文の生成、再生成
- コピー、印刷／PDF保存
- 参照した施設や生成方法の簡易表示
- API不通時も、サンプル地点・地名だけで生成できるフォールバック

**未実装：** 公的標高・土地利用の統合、深い地域史検索、自然言語AIによる生成、画像書き出し、保存／共有、所在地の距離厳密検証、全国情報の網羅性。

## 6. 初版で重視する品質

- API障害や地名検索失敗を隠さず、地名のみの生成へ劣化運転できること。
- 不確かな土地情報を事実として作らないこと。
- 検索候補の選択と、地点の確定を明確にすること。
- 地図を読み込めなくてもアプリ本体が壊れないこと。
- iPhoneを含むスマートフォンの画面幅に対応すること。
- 公開データのクレジット・利用条件を守ること。
- スタイルへのこだわりで使い勝手や読みやすさを犠牲にしないこと。

## 7. 将来の独自性

- **日本マンションポエム地図：** 全国の地点に紐付けた作品ギャラリー。
- **逆翻訳：** ポエムから装飾表現を外して、ごく普通の土地紹介へ戻す。
- **ポエム度診断：** 大仰さ、抽象性、根拠薄弱さなどの観点で採点。
- **地域学習モード：** 実際に参照した文化財・地形・施設への出典リンクを辿れる。
- **広告画像生成：** 土地の性格に合わせた架空広告の1枚絵。
- **名称メーカー：** 地名から架空レジデンス名を生成。
- **2地点比較：** 互いに無理やり優雅に称賛し合う広告コピーの競作。

## 8. 開発原則

- MVPは単一HTMLに近い軽量構成。GitHub Pagesに配置できることを優先。
- アプリの見た目は高級感、内部の作りは小さく明快に。
- データと生成文の境界を明示し、架空の広告である旨を常時確認できるようにする。
- 機能を追加するたびに、「その土地らしさ」「笑えるほど荘厳」「根拠の追跡」「操作の簡単さ」の4点で評価する。
