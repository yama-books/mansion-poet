## 1. 原画で実際に観察できる構図

白地の横1536pxに、上段3つの大きな長方形広告、下段5つの縦長の小広告を格子状に並べる。細い明るいグレーの境界線が広告同士を分け、明朝の見出しが画像以上に存在感を持つ。上段3型のビジュアルは **墨線街並み / 暮れかかる並木道の写実写真 / 淡青の川辺と地図** と意図的に分けられ、同じ街の広告群に見えても単調でない。

テクスチャは過剰に光沢を出さず、白・ベージュ・淡いグレーを基礎とし、本文は黒っぽい明朝、施設番号や凡例に紺・緑系が少量使用される。写真風夕景だけは暗く、白い見出しを重ねる。全体に影やボタン状の角丸UIを置かず、**印刷された広告を観察するような閲覧感**がある。

## 2. 上段A：TYPE POEM｜左に詩、右に街角の細い墨線

ファイル：`REF-0001-A_type_poem.png`（原画crop x30–514, y64–545）  
構図ID：`type_poem.ink_right`  
タグ：`template:type_poem`, `composition:ink_right`, `art:ink_line`, `fit:knowledge`, `fit:bookstore`, `mood:quiet`, `use:print_front`

**視線の道筋**：紙面左上の約3行の非常に大きい和文明朝 → 右側へ消失点を向ける通りのペンスケッチ → 小さな本文 → 架空物件名・下部施設情報 → フッター。

**描画上の特徴**：
- 画像の右半分には欧州風にも見える架空の低中層街並み、歩道、樹木、建築立面を細く描く。線は墨一色に近く、必要な部分だけわずかに淡色。
- 左半分は画像が極力侵入しない領域を確保。文字と線画を同じ背景で扱うが、明朝の画数と線画の細線が混ざらない。
- コピーは3〜4行に積み、詩の短い本文をその下に置く。価格や間取り風の数字は**コンセプト画像モデルによる架空値で、出力には再使用不可**。
- 日常的な施設が主役でも、図版が「静かな街の空気」を表すため、景観を誇張した実景の証拠とはならない。

**再現ルール**：A4上段の左約55%を詩に、右約45%を独立生成した街並み線画にする。施設情報は画像へ焼き込まず下部のDOMカードで表現する。実在書店の看板を描かせない。

**弱点／回避**：長い和文見出しでは右の線画を弱めるか下段へ移す。写真を重ねると明朝の視認性が崩れるため、この版型は墨線・淡彩が基本。

## 3. 上段B：EDITORIAL｜夕景の主画像に白い見出しを重ねる

ファイル：`REF-0001-B_editorial.png`（crop x523–1009, y64–545）  
構図ID：`editorial.dusk_overlay`  
タグ：`template:editorial`, `composition:dusk_overlay`, `art:photographic`, `mood:cinematic`, `fit:urban`, `fit:city_night`, `use:print_front`

**視線の道筋**：夜に入る直前の深緑の並木＋落ち着いた窓の光 → 左下の白い大見出し → 下段の物件名・詩・周辺情報 → 横3点の小さな情景写真。

**特徴**：
- 夕景写真風の横長主図版は紙面の上半分近くを占める。木々の暗部の中に暖色の細かい点光が混じるが、全体をギラギラさせない。
- 見出しは画像左下へ重畳させ、白い明朝で2〜3行に分ける。文字の裏は背景が暗い方向を選び、光の強いエリアに文字を置かない。
- 下半分は明るい紙地へ切替。詩の説明と補助写真3枚の横並びが「暗い映画的主画像→読み物」の対比を作る。
- 同じ写真をトリミングし直して3枚と数えず、補助は書棚／緑のある街路／生活施設を想起させる一般情景を別々に生成する。

**再現ルール**：画像を文字無しで制作し、白い見出しをWeb側で重ねる。必要時には読める程度の暗いグラデーション。主図版がない場合は既存SVGへ戻す。実物件の夜景や眺望を保証する画像にはしない。

**弱点／回避**：夜間写真の暗部を強くし過ぎない。白黒印刷で背景と文字の差が失われるなら、画像外に見出しを置く構図へ退避。

## 4. 上段C：LOCATION｜淡彩の川辺＋地図と施設一覧

ファイル：`REF-0001-C_location.png`（crop x1018–1518, y64–545）  
構図ID：`location.river_sketch`  
タグ：`template:location`, `composition:river_sketch`, `art:watercolor`, `fit:water`, `fit:park`, `case:map_present`

**視線の道筋**：上部に短い和文明朝の詩 → 右上に淡青・緑の都市河川イラスト → 中央下の地図 → 右の番号付き施設凡例。

**特徴**：
- 上部の詩は「街の知性と緑」という抽象的な言葉を、右の一般景観イラストで受ける。
- 情報の実体は真ん中から下。地図が独立の画面パーツで、その右に施設名・番号・距離の列が規則的に続く。
- 白い余白の中に淡い地図、紺色の番号が散らばり、堅苦しい表ではなく編集ページに見える。
- 北矢印・縮尺・徒歩分のような表示が見本画像にあっても、**画像モデルが描いた値は無効**。現行PRINT03の位置データを用いて地図を作図する。

**再現ルール**：川のイラストは独立アセット、位置図はLeaflet／地理院タイル／座標ベース図から別レイヤー生成。施設の位置と直線距離、出典・架空注記は検証済みデータのみで付ける。

**弱点／回避**：水辺が実際に存在すると証明されない地点に、実景を連想させる写実的な川のイメージを大きく配置しない。

## 5. 下段DとE1〜E5：5つのケース見本

下段まとめ `REF-0001-D_lower_overview.png`。下段の各広告を個別cropした`E1`〜`E5`は**画像の新規生成ではなく同一原画からの切り出し**。

| ID | 見本の意味 | 真似るべき編集操作 | 絶対に真似ないもの |
|---|---|---|---|
| E1_front | 神保町・3施設・表面 | 左に大明朝、右に街の線画、最下部に施設の摘要。紙面は軽く見せる | 架空の価格・駅徒歩値 |
| E2_back | 神保町・3施設・裏面 | 見出しを小さく、地図を中央の主役にし、番号・凡例・注記を視線の順に整列 | 生成されたダミー地図と実測していない距離 |
| E3_zero | 施設0件／1枚 | 空白を生かし、詩と比較的大きな淡彩の1図版で成立させる。施設0を無理に埋めない | 例示の建築・住所・価格を実在と誤認させること |
| E4_kyoto | 京都・長い施設名称 | 長い和文名のために下部の情報帯を柔軟に組み、伝統的な図版を細い線画として右へ寄せる | 実在寺院を物件の外観として描くこと |
| E5_dense | 施設・生活情報が多い広告 | 写真を小さくし、施設情報をコンパクトな番号付き2列へ整える | 施設名・価格・経路の捏造と読めない脚注 |

**ケースの分岐**：
- E1/E2は同じ場所、同じ生成トークンで表裏が一致すること。
- E3は`case:0_locations`。空の施設カードも地図の距離注記も出さない。
- E4は`case:long_name`。施設名・自治体名を省略しない。長文なら本文・出典を次ページへ。
- E5は`case:high_density`。情報が入りきらなければ裏面に移す。画像に人数・営業時間などの追加情報を勝手に埋めない。

## 6. 推奨の素材生成指示（このREFから画像をつくり直す場合）

上段A向け：**完全な架空の住宅街の一本道を一場面の細いペン線と淡い水彩で描き、右側に寄せ、左半分を白く空ける。文字・看板・値段・地図・複数広告フレームは描かない。**

上段B向け：**完全な架空の日本のレジデンス街路を薄暮に撮ったかのような単一建築写真。並木と窓の暖色灯、左下は落ち着いた暗部を残し、文字・広告レイアウトなし。**

上段C向け：**都市の一般的な川辺と緑を淡青・淡緑の透明水彩で横長1シーン。実在河川を再現せず、川名・地図・施設リスト・文章は絶対描かない。**

紙面のレシピは[PR #34 の詳細仕様](https://github.com/yama-books/mansion-poet/pull/34)の`type_poem.ink_right`、`editorial.dusk_overlay`、`location.river_sketch`と一致させる。
