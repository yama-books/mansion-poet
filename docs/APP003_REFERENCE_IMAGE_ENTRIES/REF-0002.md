## 1. 原画の編集コンセプト

REF-0001よりも、**写真風の建築図版と文字／生活情報との配置関係が明瞭**。紙面外側は白く、各広告は薄い影で少しだけ浮かんで見える。上段の各列に淡いベージュ・青・緑のラベル帯が付いているが、これは複数案の**比較一覧の見出し**であり、個別A4広告の必須要素ではない。

和文明朝の短い詩が高い位置にあり、欧文／ゴシックの小さな施設データを補助させる。石・ガラスの集合住宅写真、緑の街路、ラウンジ、水辺と地図が共存する。高級感の核は金色や豪華設備ではなく、**主画像の画角・余白・数字の規律・誌面の読み順**である。

表面・裏面を組み合わせたサンプル、施設情報が0件の紙面、寺院らしい情景を扱う京都の長名版が下段にある。数値・施設名・地図の表示はAIが生成した例示であり、そのまま出力に再使用しない。

## 2. 上段A：TYPE POEM｜左に縦長の詩、右に物件情報、左下に線画

ファイル：`REF-0002-A_type_poem.png`（crop x25–480、y76–570）  
構図ID：`type_poem.ink_lower_left`  
タグ：`template:type_poem`, `composition:ink_lower_left`, `art:ink_line`, `fit:knowledge`, `fit:quiet_residential`, `mood:quiet`

**視線誘導**：左上の改行された和文明朝の大きな詩 → 右上の架空物件名・短い散文 → 左下の街路スケッチ → 右下の施設3件・小さなアイコン → 脚注。

**構図の要点**：
- 左列は大見出しが大部分を占める。左下の街並みはやや青みのある細線スケッチで、歩道と建築が奥へ向かう透視図。線画は文字が終わった下半分だけに置く。
- 右列は文・物件名・数字風の小さなレコードの縦積み。左の大きな詩に対して右の本文が小さく、読者は左→右→左下→右下とジグザグで読む。
- 価格や間取り例は架空のまま記録せず、現行PRINT03では出さない。右上には**正式に持っているPOEM・LOCATIONデータだけ**を流し込む。
- 右下の施設アイコンは実在施設ごとのブランドロゴや観光施設のピクトを生成するのではなく、独自の汎用線画ピクトのみ採用する。

**再現ルール**：A4本文セーフエリアの左約55%、右約40%で縦の2列を作る。左は詩＋線画、右は本文＋LOCATION。独立生成の街角線画がなければSVGを使用。

**弱点／回避**：縦の長い見出し、漢字の画数の多い施設名が右段で重なりやすい。長い名称をellipsisで省かず、本文を下へ移す。

## 3. 上段B：EDITORIAL｜外観写真を左、見出しと詩を右

ファイル：`REF-0002-B_editorial.png`（crop x498–929、y76–570）  
構図ID：`editorial.facade_split`  
タグ：`template:editorial`, `composition:facade_split`, `art:photographic`, `fit:residential`, `fit:urban`, `use:print_front`

**視線誘導**：縦型レジデンス外観 → 大きな右の明朝詩 → 中段の物件名 → 下段3つの住宅・都市情景写真 → 根拠と創作注記。

**構図の要点**：
- 一番面積の大きいのは左側の**まっすぐな外壁線を持つ架空集合住宅写真**。青く落ち着いた空、素材は灰色の石・ガラス・樹木の緑。夜景より明快で、実物の広告雑誌に近い印象。
- 右側の詩は1行を短くし、写真の直線に呼応するように改行。見出しは右上に余裕を持って配置する。
- 下部にある3枚は、光の異なるラウンジ等の室内、緑と建築、窓際の家具などの独立した情景。横幅をそろえ、写真の間隔を一定にする。
- サブ3写真は**別々の素材**として制作し、1枚のAI画像内に3分割された写真を生成しない。1画像1シーンの原則。
- 架空物件本体と実在POIの外観が混ざって、施設がその集合住宅に付帯すると誤解されないよう、キャプションで「架空建築イメージ」を明示する。

**再現ルール**：最初のPoCは`print_hero`1枚＋既存SVGフォールバックで充分。PR #33の`approved-media`契約を遵守し、サブ画像3点は正式スロット承認後に追加。補助画像がなければ色面／余白へ縮退。

**弱点／回避**：外観写真が存在するだけで所在地を連想させる。実在地点の実物写真と偽る表示や完成予想図の断定は禁止。

## 4. 上段C：LOCATION｜写真3点の帯＋地図＋番号一覧

ファイル：`REF-0002-C_location.png`（crop x943–1514、y76–570）  
構図ID：`location.photo_strip`  
タグ：`template:location`, `composition:photo_strip`, `art:photographic`, `art:map_based`, `fit:bookstore`, `fit:park`, `case:map_present`, `density:high`

**視線誘導**：上段左の明朝見出し → 右の短い解説 → 幅の揃った横3点の都市生活画像 → 左下の淡い実地図に似た位置図 → 右の番号と施設名・距離。

**構図の要点**：
- テーマは街における日常の質。3点の補助写真は書棚／公園緑地／街並みなど、文教・自然・住宅を横断する**一般情景**として分離する。
- 補助写真の下に小さな説明を置くが、実在店舗の写真だと証明されていないものは「情景イメージ」と注記する。
- 位置図は下部の左半分強を占め、淡い色の道路・施設形状の上に番号を重ねる。凡例は右半分弱に、施設名と距離を右端揃えで並べる。
- 印刷では既存PRINT03に従い、表側のLOCATION最大3件、裏面での追加周辺最大7件を分ける。地図のマーカーが実測約5ptで読みにくい問題を解消するため、番号の8pt目標と凡例との一対一対応をチェックする。
- 本見本内の地図は画像モデル製の作り物。完成形では国土地理院タイル／実座標に基づく位置関係図に差し替え、地図出典を必ず付ける。

**再現ルール**：3写真は独立アセット、地図はSVG/Leafletで実データから描き、タイトル・本文・凡例はDOMで組版。写真3点が揃わなければ写真帯を削り、地図と見出しのレイアウトへ面積を振り直す。

**弱点／回避**：情報を全部1面に詰め込むと脚注・施設名の可読性が落ちやすい。施設数によってduplexへ安全に分岐する。

- E4は長名称で詰め込まない。A4を1枚で完結できなければ改ページ。文化財・神社寺院の図版と販売レジデンスを区別する。
