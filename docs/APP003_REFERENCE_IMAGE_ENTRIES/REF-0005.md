## 上段：構図ごとの説明

### A TYPE POEM

短い詩と行間を大きく取り、川の水平方向をインクの細線で支える。淡い水彩の架空河岸は下部に独立配置。

### B EDITORIAL

見える河川ではなく暗渠の断面を主図版にし、地上の樹木と地下の流路を二層で対照させる。

### C LOCATION

都市の水脈を表す抽象線図と、位置情報の表示領域を区分。下段の図は架空模式図と常時表示する。

## 下段：印刷派生の説明

### D A4表面

右半分に水辺の風景、左に短い詩。印刷余白を大きくする。

### E A4裏面

架空の番号付き関係図と３項目凡例、出典欄の配置見本。縮尺・北矢印は設けない。

### F 白黒派生

水面の線密度と地平線で違いを出し、色なしで情報を識別。長い施設名は改行して確保。
