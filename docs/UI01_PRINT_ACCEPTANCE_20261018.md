## 目的と変更範囲

ユーザーのモバイル確認と並行して、非ローカルWeb実装で独立して修正できる表示・印刷を改善する。外部の有料ブラウザ自動操作サービスTinyFishは**使わない**。元データAPIの照会数、POEM辞書630フックとLOCATIONコピー117組、SAFE-01安全判定には触れない。

### このPRのコード変更

1. 印刷：従来の「画面高100vh」「高い濃色塗りつぶし」「施設広告が分割され得る」印刷CSSを置換。A4 / 13mm余白、白地・濃色文字でポエムを組み、LOCATIONは別ページから開始。カードに `break-inside:avoid`、広告0件時は空のLOCATION欄を非表示にする。
2. 320〜360px級の狭幅：ブランドとモード選択の余白・文字サイズ、コピー操作ボタンを行幅100%、タップ高さ44pxに調整。
3. `prefers-reduced-motion:reduce`：CSSトランジション・アニメーション・スムーススクロールを停止。ポエム生成後のJSスクロールも利用者の設定を尊重。
4. テスト3件：印刷CSSと空カード処理、狭幅/低モーションルール、JSの低モーションスクロール。実機でA4ページ分割・禁則や文字位置が崩れないかは別受入。
