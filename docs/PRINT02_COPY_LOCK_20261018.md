# PRINT-02 / COPY-LOCK-01｜2種類の印刷広告と旧地点のコピー禁止

2026-10-18 JST / APP-003 / POÈME / ESTATE

## 変更の根拠

ユーザーからの確認：印刷とコピーは基本動作するが、神保町のPOEM＋LOCATION3件が掲載された例を「A4広告一枚」にまとめたい。別の実機指摘として、地点を中野→京都へ変更したあと「この街を、詩にする」を押す前に**ポエム単独コピーが有効のままで、旧地点の文章をコピーできる**。

直近の添付PDF（刈谷町の例）は、ポエム1ページ・LOCATION1/2が2ページ・LOCATION3が3ページの計3ページ。印刷改ページが固定されていたことが原因の一つ。旧仕様は `resetLocationHighlights` でLOCATION付きコピーボタンだけ無効化し、`#copyBtn` と `#printBtn` は維持していた。

## 本PRの修正

### COPY-LOCK-01：データの世代管理

- `generatedCurrent` がtrueになるのは、指定地点の生成が正常なコード経路を完了した場合のみ。
- 地点プリセット切替、地図クリック、検索結果選択、住所文字入力時に必ずfalseに戻す。ポエム本文、見出し、PROPERTY、根拠の古い表示は入力待ちプレースホルダに変え、LOCATIONとTHE REALITYもクリア。
- `COPY THE POEM`、`COPY POEM + LOCATION`、`PRINT / PDF`、`REGENERATE` を無効化する。ボタンだけでなくコピー関数・印刷クリック処理でも `generatedCurrent` を確認。
- 同一地点の再生成中もクリップボードや印刷を無効化。ネットワーク失敗でも地名のみのPOEMを生成した時点で有効に戻る。古い非同期応答の破棄は既存のversion比較で保護。
- 初期サンプル表示は残すが、ユーザー自身が生成するまではコピー・印刷不可とした。

### PRINT-02：2種類を選べる印刷

「PRINT STYLE」のセレクトを追加し、PRINT / PDFを押すと選択を `document.body.dataset.printLayout` に反映してから標準ブラウザ印刷を開く。どちらもA4、元のポエム・3枚の施設PR・住所・距離・出典・注記を保持し、文字切り捨てはしない。

- **案1「コンパクト」**：既存の縦の順番を維持。余白・行間・文字サイズ・カードの高さを縮め、ポエム→LOCATIONの強制改ページを解除。長文等でA4を超えれば2ページ以上になりうる。
- **案2「1枚広告」**：上部にポエムとProperty、下部に主役の大きなカード＋補助カードを2列で構成。3件程度の一般的なケースをA4に収めるのが目標。文章の途中カット・CSS固定高による内容欠落は行わず、長文やフォント差で2ページ以上になる場合は欠落なく印刷されるようにする。
- ユーザーの「どちらも見たい」に応えるため、今回のモック比較PDFは別ファイルで作成（神保町のユーザー提示本文をそのまま用いる説明用の見本）。**モックはローカルPDFレンダラーの成果であり、GitHub Pages上のブラウザ印刷結果とは同一と主張しない**。再現の正本は本PRのHTML/CSS/JS。

## テスト

- 地点変更直後にポエム単独・広告付きコピー、印刷、再生成を無効化、表示内容も旧地点から更新。京都で新規生成して復帰。
- テキスト入力直後にも生成前コピー/印刷禁止。
- 2種類の選択と標準印刷起動、CSS規則存在をテスト。
- 既存の123件、UI-01印刷追加3件をすべて回帰。

## 実機受入（ユーザーが確認する項目）

1. 中野で生成→京都を押す→生成前に **両方のCOPY/PRINT/REGENERATEがグレーアウトし、旧POEM/LOCATIONが残らない**。
2. 京都で新しく生成→コピー/印刷復帰、内容が京都に変わる。地名を手入力したときも旧COPYが無効。
3. 神保町で3枚のカードを生成→印刷スタイルの案1・案2をそれぞれ印刷プレビューで比較。両方とも、長い住所や文章が欠けていないこと、余白が不自然でないこと、ページ数を確認。
4. 3枚のカードがなくAPI失敗・無施設になった場合もPOEMだけが欠けずに印刷できること。
