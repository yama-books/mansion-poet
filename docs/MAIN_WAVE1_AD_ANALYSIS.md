## 1. 今回の目的とサンプル選定

Pilotは三井・三菱地所・野村に偏り、東京圏と大都市型ポエムの密度が高かった。今回は東急・複数社共同開発・地域デベロッパーを加え、札幌／京都／福岡／那覇の多様な訴求を採取。

候補は既存広告ページの**実際に読める公式サイト**から選定。地域・事業者を意図的に変えたサンプルで、市場のランダム標本ではない。

取得法：Firecrawlから14ページでHTTP 200・本文を取得。S12のTOPのみFirecrawlのレンダリングがタイムアウトしたが、公開Webページを別経路で開いて本文と公式URLを確認したため対象に含めた。この15ページについて**画面ビジュアルの直接観察をしたとは記録しない**。

## 3. 公式サイト3ページ別メモ

### S09 ブランズ札幌大通東｜東急不動産

[TOP](https://sumai.tokyu-land.co.jp/branz/odori-higashi/)／[CONCEPT](https://sumai.tokyu-land.co.jp/branz/odori-higashi/concept/)／[LOCATION](https://sumai.tokyu-land.co.jp/branz/odori-higashi/location/)

- TOP：駅徒歩・広い地下歩行ネットワーク・大型商業施設や具体の販売価額という定量情報を早い段階から示す。
- CONCEPT：札幌の変化、創成イーストの再開発、環境性能・暮らしの先進性を組み合わせる。歴史中心ではなく「都市の未来」というブランド形成。
- LOCATION：大通公園、サッポロファクトリーなど個別施設の距離、歴史的建物、自然、医療等を分ける。
- **アプリへの示唆**：地下動線や季節の通行快適さは単純な店舗件数・直線距離には還元できない。将来的に交通は道路経路と歩行者ネットワークも検討する。ただし未提供データから「冬でも快適」と断定しない。

### S10 KYOTO COCO CITY｜京阪電鉄不動産ほか

[TOP](https://www.kyoto-coco-city.jp/)／[ABOUT](https://kyoto-coco-city.jp/about.html)／[LOCATION](https://kyoto-coco-city.jp/location.html)

- TOP：京都の古都的な格式ではなく、環境・未来・エネルギー・多世代の都市づくりを主題に置く。
- ABOUT：マンションと戸建て等の複合街区という長期計画、多様な居住者の交流、緑化とサステナビリティを繰り返す。
- LOCATION：FLAGとCUBEの施設距離を**それぞれ別計算**し、徒歩と自転車を区別。京都駅周辺の大規模商業や文化施設へのアクセスを説明。
- **アプリへの示唆**：同じ地名でも起点が異なれば施設までの距離は変わる。DREAM/REALITYのREALITY側は必ずユーザーの選択ピンから距離を計算する。表示条件に起点座標と経路モードを明記する。

### S11 エンクレストガーデン福岡｜えんホールディングス

[TOP](https://www.en-hd.jp/gardenfukuoka/)／[CONCEPT](https://www.en-hd.jp/gardenfukuoka/concept/)／[LOCATION](https://www.en-hd.jp/gardenfukuoka/location/)

- TOP：効率偏重の時代に「暮らしの本質は何か」を問いかける。邸宅の格より人生観を語るポエム型。
- CONCEPT：緑・花・光・季節、住民の関係、日々の小さな幸せを連鎖させる。質問→価値観の転換→住まいという**物語の構文**を採れる。
- LOCATION：公園と住まいの接続、複数スーパー／ドラッグストア／クリニック／学校／金融を具体的な距離や交通手段と共に表示。建物の複数棟から施設までの距離が幅を持つ。
- **アプリへの示唆**：THE REALITYは買い物・子育て・文化・医療など生活の目的別に整理し、道路距離のある広告と単純な直線距離の違いを説明する。

### S12 アルファステイツ那覇松尾｜穴吹興産

[TOP](https://www.anabuki-style.com/nahamatsuo/)／[CONCEPT](https://www.anabuki-style.com/nahamatsuo/concept_design/concept/)／[LOCATION](https://www.anabuki-style.com/nahamatsuo/location)

- TOP：国際通り・ゆいレールなど身近な交通と立地を前面に出す。2026年11月下旬の予告広告と明記されていた（閲覧時の記載）。
- CONCEPT：沖縄の海・歴史・観光・食などを大きく語ってから、那覇松尾の生活圏へ戻る。リゾートの余暇と都市生活の併置。
- LOCATION：観光・公設市場・バスターミナルと医療・保育・金融など目的別に施設名／広告掲載距離を整理。
- **アプリへの示唆**：大きな地域（沖縄県）のイメージと、ピンの周囲850mの生活利便を**混同しない**。詩の比喩は広域の文化に触れても、THE REALITYの具体店舗は調査半径・選択地点に限定する。

### S13 グランドパレス識名｜第一交通産業グループ

[TOP](https://gp-shikina.jp/)／[CONCEPT](https://gp-shikina.jp/concept/)／[LOCATION](https://gp-shikina.jp/location/)

- TOP：物件写真と案内、一般的な生活・家族への訴求が中心。大げさな自己宣言は前面に出ない。

- **アプリへの示唆**：未来の公共施設・路線計画を「現在利用可能な施設」として紹介しない。公共プロジェクトの実現可能性は別途公的資料で検証する。現時点の施設一覧に自動混入させない。

## 5. THE REALITY機能への新たな要求

この5物件によって、単なるPOI数や最寄り店舗距離では表せない差が見えた。

1. **地理的スケール**：都道府県全体のイメージと、ユーザー選択ピンから1km以内の情報を分ける。
2. **起点の厳密さ**：FLAG/CUBEや複数棟で距離が異なることから、表示した起点座標を保持。
3. **交通手段**：徒歩、自転車、地下通路、公共交通を同じ「分数」に換算しない。
4. **未来の状態**：`existing / planned / announced / unknown` を概念上分ける。標準の「生活施設として使える」リストには原則existingの信頼できる施設だけ表示する。
5. **施設タイプ**：大型商業と日用品店、学校、金融、病院、公園などを独立カテゴリーとして扱う。
6. **施設案内と広告表現**：「暮らしやすい」「便利」「安心」は広告の主張であり、アプリでは客観的な取得可能情報に分解。
7. **情報の未収録**：施設が見つからないとき、存在しないと断定しない。

設計の正本：[LIVING_ENVIRONMENT_SPEC.md](LIVING_ENVIRONMENT_SPEC.md)。今は設計改善の根拠として記録し、コード変更は別タスクで扱う。

## 6. 現在の研究母数と限界

- Pilot：**8物件・24公式ページ**、文章の一次レビュー済み。画面直接確認は6/8。
- Main Wave 1：**5物件・15公式ページ**、文章の一次レビュー済み。画面直接確認は0/5。
- **合計13物件・39公式ページの文章レビュー**。うちPCファーストビュー直接確認6物件。
- 採点は同じ担当の暫定評価で、独立したブラインド一致率ではない。
- 2026-10-17時点でまだ、全30物件の研究完了でも、アプリ機能実装でも、スマホ実機テスト成功でもない。
- S13を追加して初めてP1の対照例が入った。計画では低ポエム度広告を少なくとも5件入れるため、あと4件以上の候補が必要。
