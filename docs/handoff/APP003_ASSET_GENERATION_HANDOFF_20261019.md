## 3. デザイン・生成プロンプトの共通方針

### ポジティブ仕様

洗練された日本の建築雑誌／高級住宅広告にふさわしい、建築写真風または精密な3D建築イメージ。実在案件・地名・特定会社を参照しない**完全な架空建築と一般的な自然**。素材感（石、ガラス、木、植栽、柔らかい光）、深度と水平垂直の整合、上品で低彩度のトーン、文字を後載せできるネガティブスペース。要素を詰めすぎない。地元施設の写真に見せかけない。

### NG仕様

- 企業ロゴ、実在の建築ブランド名、物件名、看板の固有名、販売価格、電話番号、文章の自動描画。
- 既存マンション公式ページの構図の細部までの模写。著名建物・文化財をそのまま物件本体と誤認させる再現。
- 実在の施設が建設されていることを示す位置情報、架空の施工／設備仕様の断定。
- 人物・顔の不要な生成、人物や植栽の不自然な増殖、ガラスの反射の矛盾、崩れた幾何。
- 不自然な極端なHDR、ギラギラした金色、安易な豪華さ、色だけを換えた大量の同一絵。
- ImageGen出力を地図のPOI固有の正確な外観証拠として使用すること。

### 画像への文字は入れない

物件名・詩・価格・出典・注記の文章はWeb側がDOM/SVGで重ねる。画像自体に文字を焼き込むと、内容変更、コピー、禁則、翻訳、印刷が困難になるため避ける。

## 4. 制作単位と100パターンへの拡張

**段階A：10枚の原画**。テーマの分散、1/3以上が「昼・夜の建築以外」、縦横を混在。1枚の制作後すぐ小さな画面と広告組版に仮に配置して採点する。

**段階B：20〜30枚の原画**。試作段階で採用できたジャンルのみ増やす。建築／内観／自然／夜景／歴史文教／抽象などのカテゴリで不足分を埋める。

**段階C：合計約100バリエーション**。別に生成した原画と、許容されるcrop・露出・色温度・文字重ね余白などの派生を組み合わせる。原画と派生のIDを別々に数え、sceneId / variantId / parentAssetIdで由来を追跡。必要であればその後**独立した100原画**を目標に見直す。

どの段階でも、入力候補100枚をサイトで一括ロードしない。本体側の最初の表示は1枚、その他は条件付きlazy load。実画像の書込み先と公開の方法は本体IMG-00担当と協議する。

## 5. アセット納品メタデータ契約

本体[IMG-00](../APP003_VISUAL_IMPLEMENTATION_PLAN_20261019.md)のmanifestスキーマを変更せず採用する。書込み先は初期段階では素材担当の作業出力（ZIP + CSVまたはJSON）に限定し、正本Repoへの公開画像投入とは区別。

1枚ごとの必須データ：
- assetId / sceneId / variantId / parentAssetId（原画ならnull）
- genre・themes・slots / orientation / focalPoint x,y
- original dimensions / format / rendition screen／printごとのwidth,height,bytes
- file hash / generatedAt / generation tool（記録可能範囲）/ promptRecipeId・promptText
- kind=generated_illustration、caption=架空建築イメージ 等
- provenance=assistant_generated、rightsStatus（unknown/review_required/approved）、permissionToRedistribute（未確認はfalse）
- reviewer / reviewStatus（candidate/accepted/rejected）/ rejectionReasons
- imageShowsRealPOI=false などの誤認防止フラグ、注意書きの種類

例：画面用 1200〜1600px幅のWebP、印刷原画は十分な解像度を別途検討。300ppiのA4全面は約2480×3508pxに相当するが、画像をA4全面に配置しないなら必要画素数は縮小できる。**生成した1,024px画像を機械的に2,400pxへ拡大してネイティブ高解像度だと報告しない。** JPEG/PNG原本はレビュー用に保持してよいが、Web納品は圧縮版を別出力とする。

実体ファイルのpathが分からない、読戻せない、MD5/SHAが未計算、画像生成に失敗した場合は該当項目をmissingにして進捗から除外する。

## 6. 一枚ごとの品質審査

### ハードゲート（必須すべて）

- [ ] 実在の物件・広告・ブランドのコピーでない
- [ ] 実在する地域／施設の証明・外観写真と誤認させない
- [ ] ロゴ・価格・看板文字・不要な人物を含まない
- [ ] 画角がheroまたはresidenceで実際に使える、端で建築が切れない
- [ ] 建築幾何・手すり・窓・反射・植栽・人物影に明らかな破綻がない
- [ ] 作品の物語と、色・撮影角度・空間が一致している
- [ ] 画像出所・生成手段・権利審査状態を記録
- [ ] 画像未ロード・印刷画像無効ならSVGへの安全なフォールバックができる（本体側試験）

### 暫定評価（APP-003独自で、企業の公開採点ではない）

視覚の説得力 0〜4、建築整合 0〜4、素材感 0〜4、紙面に文字を載せる余白 0〜4、用途別crop適合 0〜4、独自性 0〜4。いずれか1項目0点なら再制作候補。採否は平均点だけでなく構図・他資産との差とハードゲートを重視する。初回10枚では二重に同質の作品を採用しすぎない。

**採用率の見極め**：最初の10点のうち、権利・破綻・組版で5点未満しか使えない場合は、続けて20枚を作らずプロンプトを修正する。目標は10枚中7枚以上の暫定合格とするが、これは経験的な推定目標であり初回データで調整する。
