## 文言の品質基準

1. 見出し案10件は**着眼点が異なる**。抽象名詞・「都市」「邸宅」「未来」の安易な繰返しを避ける。
2. ユーザーが思わず笑う程度の過剰な広告レトリックと、事実と区別できる創作表現を両立。
3. 業態・ブランドの**実際の確認証拠以上の具体的事実を言わない**。ラーメン二郎と「二郎系」、天下一品と一般ラーメンを混同しない。商標・公式コピーの転載も避ける。
4. タグが表すだけの確度で「赤いポスト」「学校の進学実績」「神社の御利益」「古代からの暗渠」「店の人気・営業時間」などを事実化しない。
5. 生徒・支援利用者・宗教的信条の人格に対する揶揄を作らない。
6. 作品のスタイル（Heritage、Metropolis、Sanctuary）や濃度で比喩だけ変え、主題選定の事実を変えない。
