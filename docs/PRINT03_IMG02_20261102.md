# PRINT03-IMG-02

Independent branch from origin/main ee45852; no old PR re-merges.

`src/print-layout/raster-manifest.js` is the approved catalogue. Currently empty:
no real photos have been supplied/approved or silently adopted from ART/REF.
Each entry has assetId, alt, caption, credit, rightsStatus/reviewStatus=approved,
focalPoint {x,y} in 0..1, and renditions {original,print,preview,thumb}. Every
rendition has url, width, height. Paths are local raster files under
`./assets/print-approved/`; SVG and external URLs are rejected. Duplicate IDs,
missing derivatives, invalid focal points and declared print upscaling fail.

The live media selector lists approved asset IDs. The HTML hero-frame contains a
picture/img, object-fit:cover, adjustable object-position, and a regular caption.
There is no photo encoded as SVG; the rest of the layout remains HTML/CSS.
Screen uses preview; source media=print selects print. Both derivatives are
preloaded with timeout and actual dimension checks before layout. Cover-density
must be at least 240 PPI. Stale generations cannot mount over a newer one.
Asset ID and measured PPI are in __APP003_PRINT_DIAGNOSTICS.

Example entry (not an actual approved asset):

```js
{
 assetId:'example', alt:'写真の説明', caption:'写真の注記', credit:'撮影者・利用許諾',
 rightsStatus:'approved', reviewStatus:'approved', focalPoint:{x:.5,y:.4},
 renditions:{
  original:{url:'./assets/print-approved/example/original.jpg',width:4000,height:3000},
  print:{url:'./assets/print-approved/example/print.jpg',width:3200,height:2400},
  preview:{url:'./assets/print-approved/example/preview.webp',width:1000,height:750},
  thumb:{url:'./assets/print-approved/example/thumb.webp',width:240,height:180}
 }
}
```

Publish packaging copies only manifest-listed derivatives, never whole candidate
folders: `node scripts/print-assets/package.cjs OUTPUT_DIRECTORY`.
This foundation does not generate/upscale images or implement an image editor.
Future intake can adapt IMG-PIPE output to this four-role contract without merging
old PR #30/#33. No real-photo quality acceptance is claimed by synthetic fixtures.

native A4 PDF one page each, all paper text retained. Synthetic PNGs are generated
in memory by tests and are not public assets. CI is reported separately; no main
merge/Pages publication or iPhone native print acceptance yet.
