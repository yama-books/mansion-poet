## 調査の運用上の工夫

Opera Browser Connectorに依存せず、公開検索→公式サイトのページ構造確認→3ページを個別に読む方式を継続した。

- S17（神戸）3ページ、S18（盛岡）TOP・DESIGNの計5ページは通常の公開ページ取得サービスで**HTTP 200を確認**。
- S18のLOCATION、S19（岡山）3ページは公開ページ取得サービスの**短時間利用上限に達した**ため、別の公開Web閲覧手段で本文を取得。本文と公式URLは確認したが、この閲覧経路では明示的なHTTPステータス番号は記録できていない。「HTTP 200確認済み」には数えない。
- 9ページとも広告テキストと掲載生活施設について一次閲覧した。ただし、実写真・動画・モバイルの演出は今回調べておらず、Vは**N/A**。
- 広告で言及された徒歩分数・店舗名・施設利用可否の正確さは現地照合していない。他社の画像・広告文章の全文は研究GitHubに転載しない。

## 2. S17 ヴェリテ神戸ポートアイランド

公式：[TOP](https://nankaifd.co.jp/verite_mansion/kobe/)／[DESIGN](https://nankaifd.co.jp/verite_mansion/kobe/design)／[LOCATION](https://nankaifd.co.jp/verite_mansion/kobe/location)

- **TOP**：駅からの近さ、子育て・生活環境、価格という具体的な**三つの購入判断軸**を順に訴求。ひとつの壮大な見出しだけではなく、実用的な複数スライドを整理して表示する。広告は完成予想CGや交通分数の算定上の注記も記載。
- **DESIGN**：白系タイルとダークカラーを組み合わせた外観、神戸港の煉瓦倉庫に着想を得たエントランス内部など、**歴史や都市イメージ→物理的な設計素材**へ変換する表現がある。
- **LOCATION**：住宅系ゾーン、島内のレジャー、医療産業都市というエリア区分。食品店やショッピングセンター、学校、医療・薬局、大学、レジャーを用途別に取り上げる。
- **研究上の論点**：人工島という地区全体の暮らしやすさと、選択地点からの距離は別物。生活の満足度は広告が訴える価値判断であり、生成器が事実として保証してはならない。

### エンジン・UIへの応用

詩的なコピー一本勝負ではなく、**「交通・生活・価格」の広告的な三部構成**が存在する。ただしアプリは架空の物件であり、地価・住戸価格が実際に得られない以上、**価格・住戸の面積を勝手に作らない**。代わりに「街の詩→生活アクセス→データの根拠」という三部構成が適切。新たな構文コードとして増やすより、**画面・コンテンツの構成方式**として先に保存する。

## 3. S18 セントラルパーク盛南新都心

公式：[TOP](https://polestar-m.jp/1008/)／[DESIGN](https://polestar-m.jp/1008/design_landplan/design)／[LOCATION](https://polestar-m.jp/1008/location)

- **TOP**：盛岡中央公園、商業施設、平置き駐車場、岩手山の眺望または南向きなど、生活や物件の具体条件を優先。ここでの岩手山の眺望・部屋向きは実物件広告における訴求であり、**架空マンションへ転用しない**。
- **DESIGN**：山の麓の景観、建物の色と素材、大きな庇、歩行者・車両の動線を解説。季節的な雨・雪に配慮した玄関設計など、地域の気候に合わせた**具体的な建築機能**にも触れる。
- **LOCATION**：ショッピング／中央公園／健康生活の3セクション。近隣スーパーだけではなく、美術館、科学館、スポーツ、病院、保育施設、学校を横断的に示す。
- **研究上の論点**：施設が多い街の広告に「健康」「安心」の言葉が出ても、外部のデータから医療体制の利用可否、診療科や受付、学区・治安の保証は導けない。広告が参照した生活情報の時点にも注意する。

### エンジン・UIへの応用

広いPOIカテゴリを漫然と羅列するのでなく、**買物・自然／文化・医療／子育て**と、暮らす目的に応じてまとめる。住環境画面は「この地域に医療施設がある」と「診察を受けられる」とを分け、診療体制を推測しない。大きな庇などの物件固有設備はポエムの地理的根拠にはしない。

## 4. S19 デュオヒルズ岡山表町タワー

公式：[TOP](https://www.hoo-sumai.com/project/okayama-omotecho/)／[DESIGN](https://www.hoo-sumai.com/project/okayama-omotecho/design)／[LOCATION](https://www.hoo-sumai.com/project/okayama-omotecho/location)

- **TOP**：江戸からの城下町の商業エリアと、住宅・商業複合再開発タワーを接続し、街の新しい象徴として価値化する。商店街や公共交通との位置関係も同じページに提示。
- **DESIGN**：武家屋敷から劇場・映画館への土地利用の変化を、低層部のガラスや外装素材・垂直ラインの意匠で表すと説明。施設の完成予想CGを多用しているが、今回の画面実見は行っていない。共用の地域交流サロンやワークスペースも紹介。
- **LOCATION**：食品店・ドラッグストアなどSHOPPING、PARK/CULTURE、HOSPITAL、EDUCATIONを用途別に距離と併記。さらに**表町商店街の店舗をジャンル×商店街の区画で案内**しており、個別POIの距離表とエリア全体の回遊情報を分ける構造が際立つ。
- **研究上の論点**：開発予定の地域交流サロンなどは、周辺の一般公開済み施設と異なる。館内の入居者限定・予約制施設を周辺生活施設として登録しない。

### エンジン・UIへの応用

**「個々の店（point）」と「商店街のような場所・地区（area）」は別の情報**。商店街全体の歴史や店舗の多様さを活用するには、施設名一覧だけでなくエリア名や範囲、出典も必要。ただしOpenPOI/OSMから正確なエリア境界・加盟店一覧が得られるとは限らないため、現時点ではAREA表示は研究要件にとどめる。

## 5. Wave 3による仕様上の発見

1. **広告の情報段階**：S17では最初から生活・価格の3視点を見せる。DREAMを巨大にしても、REALITYへの導線は明快であるべき。
2. **地域の季節性**：S18の雪や雨を考慮した設計は重要な実例だが、現アプリは建物の設計を生成しないので「雪に強い物件」などと捏造しない。
3. **点と面**：S19の商店街は個々の店舗とは別の街の価値の単位。将来、エリア型POIを検討する余地。
4. **広告の店舗名をそのまま現実データに入れない**：店舗の営業・移転等は変化する。現行のREALITY構想は選択座標からAPIで取得することが原則。
5. **バランス改善はまだ必要**：今回の3件はP2で、P0〜1の明らかに説明主体な広告サンプルは追加できなかった。残る11物件で低ポエム度5例という研究目標を再確認。
