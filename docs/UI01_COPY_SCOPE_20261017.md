# UI-01｜コピー範囲の明確化（最初の小PR）

2026-10-17 JST / APP-003 / POÈME / ESTATE

## 実装したこと

公開版の `COPY THE POEM` は従来どおりポエムのみをコピー。別の `COPY POEM + LOCATION` ボタンを追加して、直近のPOEM本文と、その回のLOCATION広告カードの見出し・施設名・**出所粒度が区別された所在地情報**・直線距離・施設PR文章・取得元をまとめてプレーンテキストとしてコピーする。

- 初期状態およびカード0枚時は新ボタン無効。
- 地点変更時は新ボタン無効化と内部のコピー対象配列を初期化。旧地点の施設紹介を誤ってコピーしない。
- 元POEMのみのコピー本文は従来仕様維持。
- 利用できるClipboard APIを優先し、利用できない環境は旧textareaコピー処理を共用。
- 生成・再生成時の表示とコピーを同じ `lastLocationCardItems` に結びつける。
- コピー内容には徒歩所要時間、未収録住所、現地利用可否等を創作しない。注意書きを追加。
- 630のPOEMフック、117のLOCATION文言、施設取得クエリ、THE REALITYに変更なし。
