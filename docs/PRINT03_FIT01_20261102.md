# PRINT03-FIT-01

Base: origin/main ee45852. Independent branch; no old PR merges.

The live print root uses a named A4 page with zero external margin and a 296mm
sheet (1mm rounding allowance). Height/min-height/overflow are reset on its
ancestors; page breaks occur only before the second and subsequent sheets.
The actual clone is measured at the current density, then levels through 4,
without rebuilding or deleting any text/media. Measurements are recorded in
`__APP003_PRINT_DIAGNOSTICS.printFit`. An oversized clone blocks the print action.
The same measurement also runs in beforeprint.

Local validation: 207 Node tests pass. Edge native PDF test at 390px and 1280px:
one page each, all preview text retained, available height 997.984px versus
936.656px used at fit level 2. Evidence: sibling `.app003-tmp/print-fit`.
The regression is added to mobile-device CI. CI result is reported separately.
Constrained-box check: 900px available rejects level 2 (936.656px) and fits at
level 3 (861.578px). A 50px box still rejects level 4 (806.266px), retaining all
text instead of silently clipping or deleting it.

Web publication and iPhone Safari native preview/cancel acceptance are pending.
Browser viewport emulation and Chromium PDF are not iOS print acceptance.
Unusually long content continues to use the existing non-destructive multi-page
fallback; this change does not promise one page for arbitrary input.
Jev audit is unresolved: no Jev tool is available and the standing send allowlist
does not cover this repository. No local content was sent to Jev.
