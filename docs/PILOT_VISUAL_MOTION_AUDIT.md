## 観察方法と注意

- **A（直接視覚）**：Opera Browser Connectorで実ページの表示画面を観察。視覚的な特徴を記述できる。
- **B（HTML）**：公開ページのHTMLに含まれる `<video>` 属性、JSライブラリの文字列など。**実際に動画が再生された／演出が実行された証拠にはならない**。
- **C（文章）**：公開ページ本文・見出し・画像説明の確認。色やモーションを断定しない。
- **未検証**：スマートフォン表示、アニメーション開始時間・イージング・フレームレート、スクロール連動の実稼働、読込速度、演出スキップ可否とキーボードアクセシビリティ。
- 広告写真・CG・スクリーンショット自体はGitHubへ保存しない。閲覧日時と公式URL、自作の分析メモを記録する。
- 視覚Vの暫定採点は**PCファーストビュー1画面だけ**を見て文章テーマとの整合を判断したもの。サイト全体のUI品質や使いやすさを意味しない。

## UI設計に反映する暫定方針

1. **広告コピーは1つの巨大なカードだけに限定しない。** 写真・抽象ビジュアル先行（S01/S02/S06）と文字主役（S03）を分けて検討する。
2. **タイポグラフィは主題で使い分ける。** 歴史系は落ち着いた明朝／和文の余韻、都市宣言は大きな欧文・短い言い切り、生活型は読みやすい整理を優先する。
3. **画像素材は自作する。** 実広告のビジュアルをGitHubへコピーせず、SVGやCSSグラフィックスを使う。
4. **モーションは選択可能に。** 動画級の重さは避け、フェード・マスク・スライド・字間の変化などを補助的に使用。利用者の`prefers-reduced-motion`を尊重する。
5. **THE REALITYは実例の情報整理に学ぶ。** ファーストビューの「夢」の演出を妨げず、次の節でショッピング・交通・公共施設等を読みやすい文字情報として示す。
