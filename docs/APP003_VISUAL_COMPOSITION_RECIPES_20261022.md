## 0. 何をどこまで再現するか

2枚は「完成したA4入稿データ」ではなく、架空の複数広告を**1枚のグリッドに並べた視覚コンセプト画**。1枚目は墨線・水彩・夕景の混合、2枚目は写真風を多用したすっきりしたカード。双方とも、共通する**編集デザインの文法**が非常によく表れている。

実際に目視で確認できたこと：
- 上段は必ず3系統「文字主役型 type_poem」「高級誌面型 editorial」「ロケーション型 location」。
- 大きな日本語明朝、地味で細い本文、街・建築の1〜3種類の図版、下部の架空物件名／情報・施設一覧を整理。
- 細い区切り線と広い白場。図版の演出は墨線スケッチ／淡い水彩／写真風の夕景・集合住宅。
- 下段は同じ構造を別条件（表裏、施設0、京都の長名、高密度）で展開。
- 「MANSION POET」「物件価格・間取り・徒歩分数・施設名」等は画像モデルが描いた**信頼できない例示テキスト**。著作物の広告データ・測定結果・現行システムの実装値を示さない。実在物件価格・徒歩時間として採用禁止。
- 生成画像内の文字には不正確な字形や文章も混じり、ピクセルをトレースして正式な表記とみなさない。

以下のmm、pt、比率、色コードは、画像から計測した確定値ではなく**再制作のための設計目標（推定）**。端末とフォントで変わるため実A4組版で測定・調整する。

## 1. 全版型に共通する「作図文法」

### 1.1 まず情報の優先順位を固定

1. POEM見出し（1〜4行、最初に目に入る場所）
2. 主図版（写真風・線画・地図のうちその版型の主役を1つ）
3. 架空レジデンス名と短いポエム本文
4. 施設の主役LOCATION 01と補助02・03（存在する分のみ）
5. 裏面の位置関係図・周辺最大7施設・注記とデータ出典
6. 作品が創作であるという表示（すべての紙面で必須）

紙面上で「画像>本文>施設出典」と見えることはあっても、**事実と創作の区別を小さな注記だけに押し込めない**。画像は実在POIそのものを写した証拠ではない。「架空建築イメージ」「情景イメージ」を画像直下に置く。

### 1.2 A4への置き換え

- 用紙：A4縦 210×297mm、まず Consumer PDF。出力はブラウザ印刷、PDF/XやCMYKではない。
- 安全余白：左右12〜14mm、上下12〜15mm。最初のターゲットは左右14mm、天地14mm。
- セーフエリア：182×269mm前後。外枠は**画面用見本では薄く**、実際のA4では印刷可能領域を優先し、フレームは必須にしない。
- 基準グリッド：12列、列間3mm、段落と図版の間隔4〜6mm。揃えの軸は3本に絞る（ページ左端、主画像の端、施設情報の端）。
- 紙面の最小構造：マストヘッド → 見出し＆図版 → 物件/詩 → LOCATION/情報 → NOTES/SOURCES → 創作フッター。
- 本文・図版・地図・注記はHTML/DOM/SVGで**別レイヤー**にして変更可能にする。画像自体に文字を焼き込まない。
- 印刷用図版の実効ppiは掲載サイズから確認する。画像を機械的に拡大して高解像度の原本とみなさない。

### 1.3 文字組みトークン（初期設計値）

| 役割 | 提案pt（A4） | 提案書体 | 組版・規則 |
|---|---:|---|---|
| 日本語メイン見出し | 30〜42（誌面全写真重畳型は34〜48） | Noto Serif JP／游明朝／ヒラギノ明朝系 | 1〜4行、行間1.12〜1.30、禁則処理。強制的に全部1行にしない |
| 小見出し／物件名 | 14〜20 | 和文明朝、欧文はCormorant Garamond等 | 不必要なオールキャップスは欧文のみ |
| ポエム本文 | 9.5〜12.5 | 和文明朝 | 行間1.55〜1.95、1行20〜33全角を目安に |
| LOCATION見出し | 9〜12 | 和文明朝／ゴシック | 主役カードのみ14pt前後可、番号は重みづけ |
| データ・所在地・距離 | 8〜10 | Noto Sans JP等 | 数字は桁揃え、距離は「直線 約m」固定、徒歩換算しない |
| 装飾英字／章ラベル | 7〜10 | 英文セリフ | Tracking 0.10〜0.22em程度 |
| 脚注・出典 | 7.5〜8.5目標 | 和文ゴシック | 最終詰めは既存PRINT03の規定を守る。創作注記・柱は8pt未満にしない |
| 地図番号と距離目盛 | **目標8pt以上** | 和文ゴシック | 既存出力の約5pt相当は今回の改善対象 |

**既存PRINT03の自動詰めロジックは維持**する。これらは方向目標であり、勝手にテンプレートの既存フォント下限を一括変更しない。長文はA4の追加ページへ移し、本文や出典を切り捨てない。

## 2. 3つの基本版型、それぞれ2通りの「構図レシピ」

各版型に構図 A／B を持たせる。**版型＝情報の意味構造、構図＝視覚の配置、アートモード＝画像の画風**。同じ文面で違う紙面を作れることが再現性の核心。

### 2.1 TYPE POEM：言葉が建築に勝つデザイン

**A：墨線・右上スケッチ型（見本1上段左）**

- 最上部は薄いヘッダー。上半分は左53〜58%をPOEM見出し、右42〜47%を街並み線画。2つの輪郭線がごく少し重なっても文字が読める余白を残す。
- 見出しは黒い明朝、3行を基本。街並みは白い紙の上に細い墨線と淡いベージュ、視点は歩道側から斜めに伸びる消失点。
- 見出しの直下には短い詩3〜4行、その後に架空レジデンス名を横一行。データ欄は細い罫線だけで整える。
- 複数施設があるなら主役01を下部で大きく、02と03は細い行・小見出しで分ける。
- 絵の文字はゼロ。建物の看板・ロゴ・ナンバープレート・人物の識別顔も生成しない。

**B：二段エディトリアル型（見本2上段左）**

- 上段は左54〜60%に4〜6行の詩的見出し、右40〜46%に架空物件名／詩／施設3行の縦積み。
- 下段左にパースのある街並みスケッチ。図版はページの幅50〜60%、高さ25〜32%程度。右下には施設名＋直線距離の小さな一覧。
- 端正な字面と「詩があふれそうで、しかし整列している」緊張感を狙う。余計な角丸カード・影をつけない。
- 施設0件なら右側の施設枠を出さず、詩と線画の見える量を増やす。

**必須図版スロット**：ink_streetscape（推奨）または従来artTypePoem()の抽象SVG。文字主役型だけは写真がなくても完成する。

**作図ワイヤー：**

~~~text
┌─────────────── masthead ───────────────┐
│ 大きな詩の見出し          │ 線画・図版   │
│ 本文と物件名              │ 題材注記     │
├────────────────────────────────────────┤
│ LOCATION 01 （広い帯）                  │
│ 02                  │ 03                │
├────────────────────────────────────────┤
│ NOTES / SOURCES / 創作注記              │
└────────────────────────────────────────┘
~~~

### 2.2 EDITORIAL：建築写真と文字の対比

**A：夕景フルビジュアル型（見本1上段中央）**

- 主図版はページ上半分に**横幅ほぼ全幅、高さ40〜52%**の写真風都市夕景を大胆に配置。並木、暖かい窓、薄暮の空が要素。
- 主見出しは画像の左下寄りに白い明朝で重畳。2〜3行で大きく、背景は文字部分だけ自然に暗い構図を採用。読めない場合は画像の下側に濃紺から透明へ軽いグラデーションを追加。
- 下段左には架空レジデンス名、短い詩、LOCATION主役情報。右に**小さな横長写真3枚**（書棚／緑のある歩道／カフェを連想させる一般情景）を並べる。
- 写真の小さなキャプションは「街の書店を想起させる情景イメージ」等。**実在施設の写真・証拠とは書かない**。
- 物件の価格や間取りは現行アプリでは出さない（画像中の数字はAIが考えたダミー）。数値遊びの専用モック型でのみ別途検討する。

**B：外観写真＋右詩型（見本2上段中央）**

- 上段左45〜52%に縦長の架空レジデンス外観写真。建築が切れないよう視点はやや下から、空の余白を残す。右側48〜55%に3〜4行の和文見出しと本文。
- 中段に物件名を太めの明朝、架空性注記。下段は横3枚（石のエントランス、緑地、ラウンジ等）の補助画像を同じ比率で整列。
- 視線の順番は左の大写真→右の詩→物件名→下段3写真→出典と架空注記。柱・細罫だけで整え、情報が多いときは別ページにLOCATIONを送る。
- 画素の主題を拡大して切らず、focalPointを使う。画像の読み込み失敗・権利未確認は既存抽象建築SVGに置換。

**必須図版スロット**：print_hero 1枚。**任意**：print_support_1〜3（現行IMG-00の確定契約ではなく将来追加案）。最初の統合試験ではサブ写真は線画／色面で置き換えて主画像1枚から開始。

**作図ワイヤー：**

~~~text
┌────────────────────────────────────────┐
│     夕景の主画像（文章のための暗い領域） │
│  詩の見出しを画像内左下に白で重ねる      │
├────────────────────────┬───────────────┤
│ 架空レジデンス名・詩・施設 │ 情景3点の小図 │
│ 詳細と直線距離           │ 版元注記       │
├────────────────────────┴───────────────┤
│ SOURCE / FICTION NOTE / FOOTER          │
└────────────────────────────────────────┘
~~~

### 2.3 LOCATION：街と情報を「編集ページ」にする

**A：水辺・イラスト型（見本1上段右）**

- 見出しは左上に2行の大きな明朝。右上には都市の河川・街路樹・建築群を描いた淡彩イラストを横長に置く。
- 中段左は正確な位置図（地理院タイル＋中心マーカー＋番号）。中段右には施設名・分類・**直線距離**の列を1〜7件程度、薄い横罫で整理。
- 地図は装飾的な手描き地図をAIで出さず、データに基づく実際のタイルや明記した模式図を使う。生成画像は地図の**上部の情景イラスト**だけ。
- 右下の方位記号・縮尺は**正しい地図投影による場合のみ**。架空の尺度表示はしない。
- 画像の水辺が選択地点の実在する河川であると断定しない。

**B：写真3点＋地図・凡例型（見本2上段右）**

- 上段は左側に大見出し（2行）・右側に短い導入詩。そのすぐ下に**横長写真3点のストリップ**（書店的空間／緑の公園を思わせる情景／住宅街並み）を置き、各々簡潔な画像種注記。
- 下段左55〜60%に地理院淡色タイルの地図（正確な中心、番号マーカー、必要時直線距離の同心円）。右40〜45%に5〜10施設までの番号付き凡例。通常の表面はLOCATION最大3件、裏面に追加最大7件という既存PRINT03ルールを守る。
- 施設数と紙面高さが衝突したら、前面は3件・裏面で04〜10を表示し、詰め込みで地図番号を5ptにするのは避ける。
- 位置図の外側に事実の出典と創作注記を確保する。地図タイル失敗時には既存PRINT03の「座標図／模式図＋適切な注記」へ退避。

**必須図版スロット**：地図（GSIまたは根拠ある座標図、画像生成とは別物）。上段の情景画像は任意で、3点未採用の間は図を省き地図・詩の面積を広げる。

**作図ワイヤー：**

~~~text
┌──────────── masthead ──────────────────┐
│ 詩的な見出し │ 導入・短い本文            │
├─────────────┴──────────────────────────┤
│ 情景イメージ① │ ② │ ③（任意）           │
├───────────────────────┬────────────────┤
│ 地理院タイル+位置図    │ 番号/施設/直線距離│
│ 出典・縮尺・北矢印     │ 01〜03、裏面04〜10│
├───────────────────────┴────────────────┤
│ NOTES / SOURCE / FICTION NOTE          │
└────────────────────────────────────────┘
~~~

## 4. 画像素材を生成する人に渡す「図版専用プロンプトレシピ」

生成画像の対象は写真・絵**単体**。**広告の誌面、チラシ、ポスター、モックアップ、雑誌表紙、文字入りインフォグラフィックの生成を禁止**する。2026-10-22のASSET-01初回試行で「画像のコラージュ＋架空価格＋文字」が発生し不採用だったため、特に分離を厳守。

### 共通規約（全レシピに必ず追記）

> 架空の日本の建築または一般的な都市情景**1シーンだけ**を、単一フレームの独立したビジュアル素材として作る。レイアウト、ポスター、文字、ロゴ、数値、価格、看板、タイトル、枠線、分割画面、複数コマ、UI、地図、施設名、学校名、販売会社名、識別可能な実在物件や文化財の複製、人の顔は入れない。まっすぐな柱・窓枠・遠近法・自然な反射・素材の接合を整える。Web側で文字を配置するので、指定方向にネガティブスペースを確保する。自然な光、低彩度、端正な素材感。**1枚の画像ファイルに1シーン**。

### 文字を画像に生成しないための合成設計

- 写真・線画：独立した assetId、原画hash、生成日、生成手段、rightsStatus、reviewStatus、focalPointを記録。
- コピー・物件名：現行POEM/LOCATIONからテキストを挿入。
- 地図：国土地理院タイルまたは正確な座標図を別レイヤーで表示し、利用条件と出典を記録。地図や駅徒歩分を画像生成AIに作らせない。
- 写真キャプション：画像種別と架空性を注記。実POIの外観説明にしない。
- 印刷：「画面用画像の引き伸ばし」を避け、配置寸法と実効ppiでaccept判定。落ちたら従来SVG。
