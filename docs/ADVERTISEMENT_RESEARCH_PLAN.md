# マンションポエム広告研究計画

更新日：2026-10-17
対象：POÈME / ESTATE（yama-books/mansion-poet）
状態：**予備閲覧と研究計画の策定段階。本調査の30物件コーパスは未作成。**

## 1. 研究課題と成果

現行のポエムは単一の施設カテゴリを抽象語に置き換える生成が多い。本物の広告の文法・土地の意味づけ・視覚的な構成・生活利便の見せ方を調べ、生成器とUIに還元する。

研究の中心は五つ：
1. 地名・地域特徴から「広告上の価値」をどう発明しているか。
2. 文法（主語省略、名詞止め、「を」の強調、当て字、対句、句読点、余韻）。
3. 表現（歴史・継承、中心性、先進性、緑、水辺、文教、日常）。
4. 画像・フォント・余白・画面アニメーションとコピーの関係。
5. 抽象的なポエムと、駅・スーパーなど具体的な生活情報との配置・距離感。

**今回の研究は住宅マーケティングの無作為な代表調査ではない。** 生成器へ取り入れる表現の多様性を探索する層化目的抽出である。

## 2. 規模・サンプリング

まず**8物件×3ページ=約24ページのPilot**で分類軸を固め、その8物件を含む**合計30物件×3ページ=約90ページのMain**へ進む。十分な類型が得られなければ**追加20物件まで**調べる。

原則1物件でTOP（第一印象）、CONCEPT/DESIGN（理念・文章）、LOCATION/ACCESS/LIFE（生活情報）を確認。1ページにまとまっていれば3セクションを確認。パンフレット、駅看板、動画は必要に応じて補完する。1物件の調査・記録目安20〜35分、30件で約10〜18時間＋レビュー時間を想定する（あくまで作業見積もり）。

| --- | ---: | --- |
| 東京都心・湾岸 | 6 | 都心、格式、タワー |
| 東京郊外・神奈川・千葉・埼玉 | 6 | 生活、緑、交通 |
| 京都・大阪・神戸 | 6 | 古都、歴史、商業 |
| 中部・東海・北陸 | 4 | 地方都市、歴史・地名 |
| 北海道・東北 | 4 | 自然、文教、地方大都市 |
| 中国・四国・九州・沖縄 | 4 | 地域ブランド、水辺、街 |
| **計** | **30** | |

同じ開発会社に偏らず（三井・三菱・野村・住友・東京建物・東急・他）、1社最大10件まで。タワー/高価格帯だけではなく、郊外ファミリー・小規模都市型も混ぜる。ポエムらしさが薄い「普通の物件広告」も**5物件以上**含め比較する。

年代配分の試案：現役2024〜2026年20件、2015〜2023年8件、2000〜2014年2件。古い広告は公式が失われ得るので、大山顕氏の記事や現存の公開資料等から確認する。情報が得られなければ架空の例を作らず、比率を見直す。

### 飽和判定

Pilot終了後に分類ルールを整理。30件終了時、後半10件に新しい表現型がいくつ追加されたか確認。独立した類型が見つかり続ける場合だけ20件まで延長する。表現の頻度を市場全体の統計と誤認させない。

## 3. 記録方式と分類コード

将来的なメタデータ正本案：research/ad_corpus.csv
将来的な個別メモ案：research/notes/AD-001.md など
上記は**提案パスであり、まだデータファイルを作成していない**。

記録列：
~~~
ad_id,project_name,developer,brand,prefecture,city,market_segment,
campaign_year,active_or_archived,official_url,top_url,concept_url,
location_url,accessed_at,short_excerpt,copy_structure,main_theme,
secondary_theme,grammatical_devices,wordplay,city_claim_type,
visual_treatment,typography,line_breaks,motion,real_world_access_claim,
nearby_facility_display,source_notes,researcher_notes,rights_status
~~~

**言語表現**：主語省略／当て字「棲む」「澄む」「刻」／名詞止め／対句／反復／目的語「を」の強調／時制や歴史の誇張／地名のブランド化／英語・外来語／コピーの長短。

**土地主題**：歴史、都心、交通、未来、緑、河川・海、文化・文教、日常、特別な自分、邸宅の格式。

**ビジュアル**：明朝・セリフ体、全角と欧文、縦組み・横組み、写真・建築CG・抽象グラフィック、余白・色・文字の面積、画面に登場するまでのアニメーション。

**住環境の具体性**：0=生活データなし、1=駅・大都市アクセスのみ、2=複数の施設、3=生活圏地図・スーパー・医療等の具体的案内まで。

各広告の指標は0〜3：
- ポエム度（説明文→抽象的な壮大さ）
- 土地固有性（汎用→その場所と固有の関係）
- 生活情報の具体性（無→検証可能な情報を整理）
- ビジュアルと文の整合（弱→強）

Pilot中2物件を一定時間を置いて再評価し、判断が不安定な項目を定義し直す。3項目以上の大きな食い違いが生じる場合はコードブックを改訂する。最終的には実装前に人手で適用例と反例を作る。

## 7. 研究から機能への反映と完了条件

- 実際の広告から**8種類以上の構文・演出の型（研究目標）**を抽象化し、各パターンに少なくとも2事例または例外を添える。実在コピーをテンプレートとして丸写ししない。
- 「歴史→継承」「都市→中心性」「緑→余白」「地名→ブランド」など、事実と修辞の変換構造を切り出す。
- 都心・生活型広告の**具体的な施設情報の出し方を5物件以上比較**して、[LIVING_ENVIRONMENT_SPEC.md](LIVING_ENVIRONMENT_SPEC.md)の住環境表示へフィードバックする。
- 旧生成器と新しい構文を同じ代表地点でブラインド評価する。指標は広告らしさ、土地固有性、日本語の自然さ、誤情報の少なさ、再生成の多様性。
- 著作権配慮：広告写真やサイト画面を無断で公開GitHubに保存しない。必要な最小限の短い引用とリンク・分析を中心にする。機械的な大量収集、robots.txt違反、ログイン・アクセス制限回避をしない。
